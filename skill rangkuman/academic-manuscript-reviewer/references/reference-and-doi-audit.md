# Reference and DOI audit

## Two-stage validation
**Stage A — Bibliographic identity:** Verify title, authors, publication year, journal/conference, volume, issue, pages/article number and DOI/URL against publisher/official registries. Use DOI resolver, Crossref, DataCite or publisher as applicable. Check retractions/corrections if relevant.
**Stage B — Claim support:** Locate actual source passage/results and confirm that cited paper backs the nearby manuscript claim, with appropriate strength and context. If full text is unavailable, mark Claim support: Unverified, even when DOI metadata matches.

## Status rubric
- Bibliography verified + claim supported
- Bibliography verified only (full text inaccessible/unread)
- Metadata mismatch / incorrect DOI
- Source does not support claim
- Source retracted or corrected (verify notice)
- Not verified

Never invent article details. Crossref is not a universal registry for all DOI agencies. Resolve redirects and avoid treating reference count as reference quality. Use `templates/reference-audit.csv`.
