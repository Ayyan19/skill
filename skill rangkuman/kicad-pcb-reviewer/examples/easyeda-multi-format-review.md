# Example: EasyEDA Project Review

## Intake
- Identify EasyEDA Standard or Pro.
- Record version and export method.
- Request schematic and PCB source/export, DRC settings/report, BOM, placement, Gerber and drill files.
- Record exact board revision and manufacturer capability.

## Review
1. Inspect native/exported schematic and board data where available.
2. Read the DRC report and verify rules are not disabled or too permissive.
3. Cross-check schematic, PCB, BOM and pick-and-place.
4. Inspect Gerber and drill in a CAM viewer.
5. Verify board outline, layer mapping, units and origin.
6. Mark missing source data and any checks blocked by proprietary format.

## Limitations
A PDF/PNG screenshot is visual evidence only. Gerber exports do not preserve all schematic and design-rule semantics. Do not call the review complete if only manufacturing plots are available.
