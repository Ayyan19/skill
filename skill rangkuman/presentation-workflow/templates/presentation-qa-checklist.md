# Presentation QA Checklist

- [ ] Purpose, audience, slide ratio and output format confirmed
- [ ] Slide count/order and hidden slides checked
- [ ] Masters, layouts, fonts and theme checked
- [ ] Text hierarchy and content fit checked
- [ ] Images, charts, tables and media checked
- [ ] Speaker notes, hyperlinks and alt text checked where required
- [ ] Output reopened successfully
- [ ] Rendered slides visually inspected, or marked not performed
- [ ] Editable objects preserved where expected
- [ ] Source deck retained and change summary prepared
