# DOCX Review Checklist

- [ ] Source and output paths confirmed
- [ ] Edit scope and overwrite approval confirmed
- [ ] Sections and heading hierarchy checked
- [ ] Tables, images, captions, and hyperlinks checked
- [ ] Headers, footers, page numbers, and section breaks checked
- [ ] Styles and page geometry checked
- [ ] Advanced features and limitations recorded
- [ ] Output reopened successfully
- [ ] Visual render inspected, or explicitly marked not performed
- [ ] Change summary and unresolved issues reported
