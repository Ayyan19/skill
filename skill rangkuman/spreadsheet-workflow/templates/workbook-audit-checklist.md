# Workbook Audit Checklist

- [ ] Workbook and sheet inventory captured
- [ ] Hidden sheets / names / tables / filters inspected
- [ ] Formula cells distinguished from cached values
- [ ] Calculation engine and recalculation status recorded
- [ ] Units, dates, identifiers, precision preserved
- [ ] Row counts and transformations documented
- [ ] Errors and external links checked
- [ ] Macros and advanced features preserved or limitations stated
- [ ] Output reopened and spot-checked
- [ ] Source workbook retained
