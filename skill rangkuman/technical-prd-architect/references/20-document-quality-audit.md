# PRD audit and enhancement

## Review guidance
Review source fidelity, structure, contradictions, omissions, traceability, implementation feasibility, NFR measurability, data/API consistency, risk and release readiness. Use severity and confidence with direct source locations. Never silently reconcile conflicting source claims. Supply change proposal and request approval.

## Output contract
Record confirmed evidence, any proposed additions, unresolved TBDs, requirement IDs and the verification method. Distinguish direct source facts from recommendations.
