# Hardware and embedded

## Review guidance
Capture exact MCU/board and critical ICs, interfaces, voltage domains, power/current, startup/fault states, timing, memory, OTA, security, enclosures, thermal, sourcing and physical safety. Require acceptance via build, simulation and measured hardware; never infer hardware verification from compile.

## Output contract
Record confirmed evidence, any proposed additions, unresolved TBDs, requirement IDs and the verification method. Distinguish direct source facts from recommendations.
