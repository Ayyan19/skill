# API contracts

## Review guidance
Specify actors, authn/authz, endpoint or event, request/response schema, units, validation, errors, idempotency, rate, timeouts, retries and versioning. For WebSocket/CRDT collaboration define conflict behavior, presence, persistence, replay and user permissions.

## Output contract
Record confirmed evidence, any proposed additions, unresolved TBDs, requirement IDs and the verification method. Distinguish direct source facts from recommendations.
