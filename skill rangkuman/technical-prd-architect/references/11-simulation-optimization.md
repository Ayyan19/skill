# Simulation and optimization

## Review guidance
Specify solver objective/constraints, feasibility, optimality gap, runtime on stated hardware/test cases, deterministic seeds, grid resolution, termination and sensitivity. Verify no double counting (e.g. drivetrain scalar and motor efficiency map), missing mandatory stop definitions, and no-regeneration assumptions. Report infeasible cases.

## Output contract
Record confirmed evidence, any proposed additions, unresolved TBDs, requirement IDs and the verification method. Distinguish direct source facts from recommendations.
