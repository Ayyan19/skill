# Cost estimation

## Review guidance
Estimate BOM line items, quantities, MPN, source, date, unit currency, taxes, shipping, assembly, tooling, test fixture, labor, contingency and replacements. Separate estimates from verified vendor quotes. Handle missing data as TBD and avoid invented market prices.

## Output contract
Record confirmed evidence, any proposed additions, unresolved TBDs, requirement IDs and the verification method. Distinguish direct source facts from recommendations.
