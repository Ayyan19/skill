# User research

## Review guidance
Record personas as evidence-backed or hypothetical. Capture jobs-to-be-done, accessibility, environment, skills, incentives, harm, edge cases, onboarding and expected recovery. Do not invent user interviews. Identify need for consent and children’s privacy if applicable.

## Output contract
Record confirmed evidence, any proposed additions, unresolved TBDs, requirement IDs and the verification method. Distinguish direct source facts from recommendations.
