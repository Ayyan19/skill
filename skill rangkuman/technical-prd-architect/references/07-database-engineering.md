# Database engineering

## Review guidance
Define entities, keys, relationships, constraints, types, units, indexes, retention, deletion, access, migration and versioning. Cross-check cardinality against features (one vs many stops, projects/roles, runs). Snapshot simulation inputs and algorithms for reproducibility. Proposals are not approved migrations.

## Output contract
Record confirmed evidence, any proposed additions, unresolved TBDs, requirement IDs and the verification method. Distinguish direct source facts from recommendations.
