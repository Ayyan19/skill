# Review workflow and evidence

Start with exact manuscript revision, research question, claim inventory and source availability. Build a mapping of claim -> manuscript location -> supporting data/table/figure/source -> check performed -> status -> confidence. Every finding needs a traceable location and the evidence used to reach the finding. Rank scientific validity and data integrity before prose. Mark missing data as unavailable, never invent it. Distinguish reviewer opinion from demonstrated defect. Use scoped review when the request is narrow.

## Evidence classes
Confirmed by source; Independently recalculated; Inferred; Hypothesized; Unavailable; Contradicted. Keep a separate issue status Open/Resolved/Blocked. Document artifact version and date. If a table is screenshot-only, record that precise data extraction may be unreliable.
